# L3 项目 Scaffold 模板

## 核心规则

> **L1 知识只在 `20-领域/编程/` 存一份。项目中通过 `[[wikilink]]` 引用，不复制、不暂存。**

## 项目目录结构

在 `10-项目/<项目名>/` 下创建：

```
<项目名>/
├── <项目名> MOC.md          # 项目入口索引（必须）
├── 设计/                     # 设计文档、技术选型、架构
├── 数据/                     # 数据文档、收集清单、数据源
├── 任务/                     # 任务清单、时间安排、周报
├── 参考/                     # 术语表、概念索引、问答记录
├── 配置与启动/               # 环境配置、账号密码
├── 工作日志/                 # 按日期的工作日志
│   └── MM-DD/
├── 附图/                     # 流程图、架构图
└── 代码解析/                 # 项目源码分析笔记（如有）
```

## MOC 模板

```markdown
---
tags: [项目]
category: 项目
---

# <项目名>

> 一句话描述

## 设计

- [[设计/设计文稿|设计文稿]]
- ...

## 数据

- ...

## 任务

- ...

## 参考

- ...

---

```dataview
TABLE file.mtime AS "修改时间"
FROM "10-项目/<项目名>"
SORT file.mtime DESC
LIMIT 15
```
```

## 新项目创建流程

1. 在 `10-项目/` 下创建项目目录
2. 按上述结构创建子目录
3. 创建 MOC 文件（填入项目名和描述）
4. 更新 `10-项目/README.md` 添加项目链接

## 学到的知识放哪

做项目过程中学到的新知识，**直接写入 `20-领域/编程/` 对应技术栈目录**，然后在项目笔记中用 `[[wikilink]]` 引用。不要在项目目录下建 `技术知识点/` 缓冲区。
